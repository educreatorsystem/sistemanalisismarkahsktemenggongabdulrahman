# Sistem Analisis Peperiksaan — SEKOLAH KEBANGSAAN TEMENGGONG ABDUL RAHMAN

## Cara terbitkan di GitHub Pages
1. Upload `index.html` ke root repository GitHub.
2. Pergi ke Settings > Pages > Deploy from a branch > main > /root.
3. Simpan dan buka URL GitHub Pages yang dijana.

## Google Sites
Pada Google Sites, pilih Insert > Embed > By URL, kemudian masukkan URL GitHub Pages anda.

Nota: URL Apps Script, Google Sheets dan URL CSV dikemas kini berdasarkan maklumat yang diberikan. Pastikan Apps Script deployed sebagai Web App dengan akses yang sesuai dan CSV diterbitkan untuk akses membaca.
